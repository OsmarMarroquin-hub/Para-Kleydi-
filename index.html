PROYECTO

Teorema de Pitágoras

Calculadora geométrica interactiva.

Una herramienta matemática completa

Este proyecto fue desarrollado para realizar cálculos geométricos de una manera visual, interactiva y sencilla.

La aplicación permite seleccionar diferentes figuras geométricas y realizar cálculos de sus principales medidas.

Cada operación muestra el resultado y el procedimiento utilizado, mientras que los valores ingresados se representan directamente sobre la figura.

Proyecto realizado por Osmar Marroquín.
